# 🎭 The Agency (Agency-Agents) — Complete Guide & Use Cases

**The Agency** ek bahut hi powerful aur structured collection hai **specialized AI Agent Personalities** ka. Isme **100+ se zyada unique AI agents** hain, jo alag-alag fields (Jaise Engineering, Marketing, Sales, Security, Design, Finance, aur Game Dev) ke experts hain.

Ye koi simple prompt templates nahi hain. Har ek agent ke paas apni unique **identity, personality, core workflows, proven deliverables, aur success metrics** hain.

---

## 🚀 isse Kya-Kya Kiya Ja Sakta Hai? (Key Features)

### 1. AI Coding Assistants ko "Supercharge" karna
Aap in agents ko apne favorite coding tools aur IDEs ke sath integrate kar sakte hain:
* **Cursor:** Custom `.cursorrules` generate karke specific pages ke liye.
* **Claude Code / Gemini CLI / Kimi:** Terminal-based assistants me specialized agent modes ko activate karna.
* **GitHub Copilot:** Copilot agents directory me copy karke unhe active karna.
* **Aider / Windsurf / Codex:** Custom instructions aur conventions files setup karna.

### 2. Apni Custom AI Agency (Multi-Agent Team) banana
Aap multiple agents ko ek sath use karke ek complete team bana sakte hain:
* **Product Manager** se PRD (Product Requirement Document) banwayein.
* **UI/UX Designer** se interface design aur components ki guidance lein.
* **Frontend Developer** se React/Next.js code likhwayein.
* **QA / Reality Checker** se code test aur verify karwayein.

### 3. Deep Domain Knowledge & Reference Guide
Agar aap khud kisi topic par seekhna chahte hain, to inki markdown files direct read kar sakte hain. Inme industry-standard workflows, code examples, aur best practices pehle se likhi hui hain.

## 🛠️ How to Install and Use (Technically)

Repository me do main scripts hain:
1. `convert.sh`: Ye script sabhi agents ki `.md` files ko scan karta hai aur alag-alag tools (jaise Cursor, Copilot, Antigravity) ke compatible formats (JSON, TOML, XML) me convert karta hai.
2. `install.sh`: Ye script converted files ko aapke system ke specific tool configuration folders me copy/install karta hai.

### Example Commands:
* **Sabhhi tools ke liye build aur install karna:**
  ```bash
  ./scripts/convert.sh
  ./scripts/install.sh
  ```
* **Sirf Antigravity (Gemini) ke liye install karna:**
  ```bash
  ./scripts/install.sh --tool antigravity
  ```
