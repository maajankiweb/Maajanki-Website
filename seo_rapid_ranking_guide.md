# 🚀 MaaJanki Web Tech - 7-10 Days Google Ranking Guide

Website live hone ke baad search engines (Google, Bing) par target keywords ke liye **7 se 10 days ke andar rank aur index** karne ke liye ek precise, technical aur strategic checklist niche di gayi hai. Brand-new sites ke crawl cycle ko fast tracking par daalne ke liye in instructions ko follow karein:

---

## 📅 Day-by-Day Execution Plan

### 📌 Day 1: Domain Verification & Indexing Setup
Google ke bots ko website detect karwane ka sabse fast tareeqa dynamic search consoles connect karna hai.

1. **Google Search Console (GSC) Setup:**
   - Website live hote hi search console dashboard open karein.
   - **DNS Verification (Domain-level)** connect karein. Yeh subdomains, HTTP/HTTPS aur parameters sabhi data points ko track karta hai.
2. **Bing Webmaster Tools Connect:**
   - Bing par bhi verification complete karein aur website link karein (Bing dynamic indexing tools use karta hai jo indexing immediate trigger karte hain).
3. **Submit Sitemap:**
   - Console me `sitemap.xml` field me search index file submit karein:
     `https://maajankiwebtech.com/sitemap.xml`
4. **Robots.txt Validation:**
   - Verify karein ki `robots.txt` dynamic headers check clean pass kar rha hai aur index block rules active nahi hain.

---

### 📌 Day 2: Google Indexing API Integration (Instant Indexing)
*Normal indexing me Google index process hone me 4 se 15 din lagta hai, lekin Google Indexing API bypass key hai.*

1. **Google Cloud Console Setup:**
   - Google Cloud Console me ek naya project create karein.
   - **Web Search Indexing API** service ko enable karein.
2. **Service Account Key (.json):**
   - Cloud Dashboard se ek Service Account user create karke key JSON file generate karein.
3. **GSC Owner Permissions:**
   - Generate hue service account email ID को apney Google Search Console me as a **"Full Owner"** add karein.
4. **Instant API Ping Script:**
   - Apne static pages aur naye location subpages URLs ko instant Google Index queue me publish karne ke liye backend script run karein (Yeh bots ko 10 minutes ke andar index crawl request bhejta hai).

---

### 📌 Day 3: Google Business Profile (GBP) & Local Citations
Local keywords (Bettiah, Bagaha, Motihari) ko 7 days me target karne ke liye local search queries optimization non-negotiable hai.

1. **GBP Optimization:**
   - Google Business Profile verify karein ("MaaJanki Web Tech, Bagaha").
   - Primary Address update karein: `First Floor, near cinema house, Front of UCO Bank, Bagaha Bazar, West Champaran, Bihar, 845101`
   - Category check: "Website Development Service" aur "Digital Marketing Agency".
2. **Embed Map on Contact Page:**
   - Contact page par actual Google Map responsive iframe insert karein.
3. **Geo-Targeted Local Pages Interlinking:**
   - GBP profile posts me specific services page aur location subpages links add karein. Example: Bagaha client requests ko direct route karein `https://maajankiwebtech.com/locations/bagaha` path par.

---

### 📌 Day 4: Schema Markups Validation (AEO / GEO / Search AI)
Search AI engines (Gemini, ChatGPT, Copilot) aur Rich Snippets me result show karne ke liye Structured Data checks:

1. **Structured Data Validation Tool:**
   - Google Rich Results Test tool open karein.
   - Website URLs verify karein ki local business and organization JSON-LD schemes clear pass ho rahe hain aur zero warnings hain (Humne standard JSON-LD files template implement kar diye hain).
2. **AI Citations & Entity Registration:**
   - Company profile directories setup karein:
     - Google Maps profile check.
     - Crunchbase & Wikidata pages registration (AI engines knowledge base read karne ke liye in references ko utilize karte hain).

---

### 📌 Day 5-7: High-Quality Backlink Building & Social Signals
Google bots tabhi site updates regular check karenge jab doosri sites se active linking refer traffic mile.

1. **Local Business Listings (Citations):**
   - IndiaMart, JustDial, Sulekha, Indiamart aur Sulekha par listing verify karein.
   - Listing details me Name, Address aur Phone Number **(NAP)** bilkul website page schema se exact match hona chahiye.
2. **High-Authority Web Profiles:**
   - GitHub, Vercel, Behance, Dribbble par portfolios links update karein.
   - LinkedIn Company page, Facebook Page aur Instagram links create karein aur 3 high-quality posts link domain ke sath publish karein.

---

### 📌 Day 8: Performance Verification & Speed Audit
Fast rendering load speed direct index priority core ranking algorithm weight hai.

1. **Run PageSpeed Insights:**
   - Google PageSpeed Insights par site test scan run karein.
   - **Core Web Vitals Metric Goals**:
     - LCP (Largest Contentful Paint) < 2.5s
     - CLS (Cumulative Layout Shift) < 0.1
     - INP (Interaction to Next Paint) < 200ms
2. **Image Optimization Audit:**
   - (Optimizations done) Check karein ki responsive WebP images lightweight configurations load details clean execute ho rahi hain.

---

## 🚀 Pro-Tips to Index in 24 Hours

* **Manual Fetching (Inspect URL):** Live hone ke baad sub-services aur home page ko search console top bar "URL Inspection" me inspect karke direct manually **"Request Indexing"** button click karein.
* **Internal Linking Flow:** Heavy link juice flow ke liye home page body text block links standard dynamic location subpages par pass on hone chahiye.
* **Submit XML to IndexNow:** Bing, Yandex aur doosre search engines ke liye IndexNow system activate karein taaki link structure change immediate register ho sake.
